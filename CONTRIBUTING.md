# Contributing / Contribuții

Please open an issue with a small reproducible **synthetic** test before submitting a change. Describe the expected scope and current behavior. Keep documentation in English and Romanian when practical.

Do not submit proprietary source, licensed commercial codecs, private keys, passwords, real customer/cadastral files, personal data or third-party material without permission. A pull request does not expand the project's stated license scope.

For security issues, follow [SECURITY.md](SECURITY.md), rather than posting exploit details and affected private data in a public issue.
