# Security policy

Do not upload sensitive data, credentials or private SoftCAD archives in public issues. For security disclosures, use the official contact channel on [softcad.ro](https://softcad.ro/) and include only a minimal reproducible sample without user data.

The public examples do not imply that any released native binary format is safe to parse without bounds checks. No warranty, penetration-test certification or confidential support SLA is offered in this documentation package.
